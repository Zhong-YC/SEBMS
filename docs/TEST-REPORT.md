## 后端及接口覆盖

- 登录、注销、未登录401、普通用户访问管理接口403、统一错误结构。
- 本人资料修改、拒绝注入角色、密码修改使其他旧会话失效。
- 非允许来源的状态修改请求被拒绝；输入类型、长度和数量边界检查。
- 两个用户同时借最后1件仅一次成功；两次同时归还只恢复1件库存。
- 库存不足、重复归还、归还他人记录被拒绝；用户只能查询本人记录。
- 总数量不能低于借出数量；停用器材不能新增借用。
- 有关联历史的用户/器材不可硬删除，关联分类不可删除，至少保留一个启用管理员。
- 在测试库制造借用记录插入失败，确认先前库存扣减回滚；制造库存恢复失败，确认归还状态和时间回滚。
- 中文搜索、日期边界、库存统计关系、重复初始化保留已有数据。

完整测试说明见../backend/TESTING.md；原始Maven日志和XML报告在../backend/target/test-evidence/。

## 浏览器实际操作

1. 管理员登录后查看统计和用户管理，新增“浏览器验收篮球”，数量1件。
2. 普通用户student登录，器材列表显示该器材1 / 1；确认借用后显示0 / 1及“暂无库存”。
3. “我的借还”显示记录#2，状态“借用中”；确认归还后变为“已归还”，归还时间2026-10-13 14:45:31。
4. 返回器材列表，数量恢复1 / 1，借用按钮重新可用。
5. 管理员工作台显示上述已归还记录；最后一次验收快照显示总量36、库存36、借出0，满足库存关系。
6. 浏览器检查了窄窗口导航抽屉及桌面工作台；最终工作台浏览器错误日志为空。

工作台统计包含具名验收数据；库存余量包含停用器材，页面已明确说明。截图采集于重启前；重启后会话需要重新登录。

## 复现

- 启动：根目录start.cmd；停止前后端：stop.cmd。
- 后端MySQL测试与前端构建：先启动数据库，再在PowerShell执行scripts/test.ps1。
- 实际HTTP验收：应用启动后使用Python3执行scripts/smoke_test.py；该脚本会新增具名验收数据并保留历史。
- H2测试及独立数据库配置见backend/TESTING.md。
