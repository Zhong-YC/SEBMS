# 第一阶段验收清单

每项只有取得实际运行证据后才能勾选。结果写入 TEST-REPORT.md。

## 核心演示

- 管理员登录，创建分类与器材；总量与可借数量一致。
- 普通用户登录查询器材，现场交接时借用1件。
- 本人借用记录显示借用中，库存减少1。
- 归还后记录显示已归还和归还时间，库存恢复1。
- 管理员可查询所有记录，统计关系成立。
- 普通用户可修改自己的显示名/密码，不能修改角色或其他用户资料。

## 异常与安全

- 未登录请求401，普通用户调用管理接口403。
- 库存0借用失败；两用户同时借最后1件恰好一次成功。
- 他人归还失败；重复归还失败，不增加库存。
- 停用器材不能再借，已有记录可按业务完成归还。
- 有记录器材/用户不能硬删除；有器材分类不能删除。
- 总量调整不能少于当前借出量。
- 状态修改跨站Origin拒绝；密码哈希且不返回前端。
- 退出后原会话不可继续使用。
