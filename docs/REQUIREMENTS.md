# 项目需求与第一阶段验收

依据：上级目录开题报告.docx、A2332钟苑财-任务书.doc，以及用户确认的无新增要求。
技术：Java 17、Spring Boot 3.5.8、MyBatis starter 3.0.4、MySQL 8；Vue3、Element Plus、Axios、Vite。选择已缓存兼容版本，不以最新版本为目标。
两类角色 ADMIN/USER，登录后使用。无开放注册，管理员维护用户。
管理员维护用户、分类、器材名称描述总数量与启用状态；查询全部记录及统计。
普通用户查询可借器材、借用、归还本人未归还记录、查询本人历史；修改本人显示名和密码。
每条借用记录1件器材，BORROWING/RETURNED；线下交接同步登记，无审批。
4张核心表 users/equipment_category/equipment/borrow_record。
同一器材 totalQuantity=availableQuantity+借用中记录数。调整总数不得小于已借数量。
已有历史记录用户/器材禁止硬删除，停用替代。分类被关联时不可删除。
统计：器材件数、品种数、库存余量（包含停用器材）、借出件数、用户数量（管理员）。
阶段验收：可本机启动，中文界面，管理员管理器材，用户完成查询借出归还全流程。验证库存不足、并发最后1件、重复归还、越权及关联删除。提供源码、建表/演示数据、启动步骤、测试记录。
